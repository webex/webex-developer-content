Using the Bring Your Own Data Source (BYoDS) Node.js SDK, developers can seamlessly integrate into the powerful BYoDS architecture with their own data sources for use cases such as `Virtual Agents` and `Type Ahead`.

---

From simplified storage and refreshing of the service app tokens to verification and rotation of `JWS tokens`, this SDK also empowers developers to configure their own data sources without having to worry about the specifics of integrating into the BYoDS architecture. With a commitment to performance, customizable storage interfaces, and robust security features, the BYoDS Node.js SDK provides a foundation for creating secure data sources.

## Versions

The current major version of the BYoDS Node.js SDK is `1.0.0`. The `next` version of the BYoDS Node.js SDK contains the latest features and fixes. Visit the NPM [versions](https://www.npmjs.com/package/webex?activeTab=versions) page to determine the latest version you can upgrade to.
