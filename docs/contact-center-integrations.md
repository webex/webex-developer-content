> Official Webex documentation: [View this page on Webex for Developers](https://developer.webex.com/docs/contact-center-integrations)

Webex Contact Center integrations now use the shared Webex integration, scope, and authentication documentation.

## Create an integration

Use the [Integrations](https://developer.webex.com/docs/integrations) guide to register an OAuth integration, configure redirect URIs, and obtain its client ID and client secret.

## Scopes

Use [Integration Scopes](https://developer.webex.com/docs/integration-scopes) to review the available Webex Suite and Webex Contact Center scopes. Select only the scopes required by your application.

## Authentication

Use the [Authentication](https://developer.webex.com/docs/authentication) guide to request user authorization, handle the OAuth callback, exchange the authorization code, and refresh access tokens.
