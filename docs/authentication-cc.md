> Official Webex documentation: [View this page on Webex for Developers](https://developer.webex.com/docs/authentication-cc)

Webex Contact Center integrations now use the shared Webex authentication documentation.

## Authentication

Use the [Authentication](https://developer.webex.com/docs/authentication) guide to request user authorization, handle the OAuth callback, exchange the authorization code, refresh access tokens, and call Webex APIs.

## Integration registration

Use the [Integrations](https://developer.webex.com/docs/integrations) guide to register an OAuth integration and obtain its client ID and client secret.

## Scopes

Use [Integration Scopes](https://developer.webex.com/docs/integration-scopes) to review the available Webex Suite and Webex Contact Center scopes. Request only the scopes required by your application.
