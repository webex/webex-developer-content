> Official Webex documentation: [View this page on Webex for Developers](https://developer.webex.com/docs/cc-web-widgets-introduction)

Accelerate your integration with prebuilt Webex Contact Center (WxCC) UI components. The Contact Center Widgets package provides ready-to-use React components that let you add agent-facing capabilities like station login, agent state, task handling, and call controls with minimal code. Use the guides below to get started quickly.

## Getting Started Guides

- **[Quickstart Guide](https://developer.webex.com/docs/cc-web-widgets-quickstart)** - Quick integration guide with code examples for existing projects.
- **[List of Widgets](https://developer.webex.com/docs/cc-web-widgets-list-components)** - Browse all available widgets and their documentation.
- **[AI Assistant](https://developer.webex.com/docs/cc-web-widgets-components-aiassistant)** - Add Real Time Assist to the active task experience.

## Version

Please refer to the `package.json` file section in the [Quickstart Guide](https://developer.webex.com/docs/cc-web-widgets-quickstart) for the recommended version of all the dependencies working together.

For the latest version of `@webex/cc-widgets`, please visit the [npm](https://www.npmjs.com/package/@webex/cc-widgets) page.

## Supported Browsers

The Webex Contact Center Widgets have been tested on the browsers listed below.

- Google Chrome (**Recommended**)
- Mozilla Firefox
- Microsoft Edge
- Safari on MacOS

Ensure that you are using one of these supported browsers for the best experience.

## List of Widgets

The widgets package offers a set of ready-made components to enhance agent workflows:

- **StationLogin**: Render an agent station login & profile update experience.
- **UserState**: Display and manage agent states like available, idle, busy.
- **IncomingTask**: Present and respond to incoming tasks with accept or reject actions.
- **TaskList**: Display, toggle and manage multiple tasks in a list view.
- **CallControlCAD**: Provide active task capabilities such as hold/resume, recording, consult/transfer, end, and wrap-up.
- **OutdialCall**: Enable agents to make outbound calls directly from the contact center interface.
- **DigitalChannels**: Manage chat, email, and social media customer interactions in a single embeddable component.
- **AIAssistant**: Provide an AI Assistant panel with Real Time Assist suggestions for the active task.
