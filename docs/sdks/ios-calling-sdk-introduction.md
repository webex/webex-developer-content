The Webex iOS Mobile SDK integrates calling functionality into mobile apps, and supports both Unified Communication Manager (UCM) as well as Webex Calling.

---



> **Info**
>
> Explore detailed documentation and code snippets for the iOS SDK on the [GitHub Wiki](https://github.com/webex/webex-ios-sdk/wiki).



The SDK enables dialing and receiving calls, and includes additional features such as call holding, transferring, and merging.



> **Info**
>
> There are multiple versions of the Mobile iOS SDK. Use the full SDK for UCM calling integration. For more information, see: [Integrating the iOS SDK](https://developer.webex.com/docs/sdks/ios-meetings-sdk-integrating-the-sdk).



If you're in a hurry, see our [Quick Start Guide](https://developer.webex.com/docs/sdks/ios-calling-sdk-quickstart).
