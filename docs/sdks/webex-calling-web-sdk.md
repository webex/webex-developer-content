Introducing the Webex Web Calling SDK – your gateway to unlocking the power of seamless communication within your applications.

---

With the Webex Calling SDK, you can effortlessly integrate fundamental audio calling capabilities into your solutions, enhancing the way your users connect. But that's just the beginning. Our SDK goes beyond the basics, offering a comprehensive set of features including supplementary services such as hold, resume, and both blind and consult transfers. Additionally, you gain access to essential features like voicemail, call settings, contact management, and noise reduction, allowing you to create rich and immersive communication experiences that meet the unique needs of your users.

Elevate your applications with the Webex Calling SDK and redefine the way your users connect and collaborate.

To get up and running, see the [Quickstart Guide](https://developer.webex.com/docs/sdks/webex-calling-sdk-web-quickstart).

It's your playground to discover and learn! Use the links below to get started. 

## Versions

The current major version of the Web Calling SDK is `3.7.0`. The `next` version of the Web Calling SDK contains the latest features and fixes. Visit the NPM [versions](https://www.npmjs.com/package/@webex/calling?activeTab=versions) page to determine the latest version you can upgrade to.

## Supported Browsers

The Webex Web Calling SDK has been tested on the browsers indicated below. Limitations are mentioned in braces.

* Google Chrome 117 or later
* Mozilla Firefox 118.0.2 or later (On-demand stats retrieval and post-call stats are not supported)
* Microsoft Edge 117 or later
* Google Chrome 117 Android or later
* Safari on MacOS Version 17 or later
* Safari on iOS Version 16 or later
