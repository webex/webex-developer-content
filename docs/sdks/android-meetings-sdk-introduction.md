The Webex Meetings Android SDK is a powerful toolkit for integrating Webex Meetings functionality into mobile applications.

---



> **Info**
>
> Explore detailed documentation and code snippets for the Android SDK on the [GitHub Wiki](https://github.com/webex/webex-android-sdk/wiki).



The SDK allows developers to add audio, video, and screen sharing features to their iOS or Android apps. It supports participation in all types of Webex meetings and provides a comprehensive set of APIs for customizing the meeting experience.
