## Overview

Assign the Compliance Officer role in Webex Control Hub to people who need to monitor and manage organization content. Compliance scopes let authorized integrations access data across the organization. The Events API supports monitoring and archiving activities after they occur; real-time file DLP checks files before other space members can access them.
