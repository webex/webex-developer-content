## Verify Data Bindings

Load the widget with the JSON layout and confirm that its configured properties receive the expected STORE values. Change a relevant agent or interaction value and confirm that the widget updates. If a binding stays empty, check the exact STORE path and property name. For title updates, confirm that the layout event identifier matches the event dispatched by the widget.
