## Article introduction

---

Federated through External Registry servers are developed by third parties and imported from an external registry. Cisco does not own these servers, and these servers are meant to be consumed by Webex AI clients. If you have any issues with the functionality of one of these servers, please reach out to the developer using the links below.

## Selected section

## Zine

Zine.ai provides a suite of MCP servers that extend your AI assistant's capabilities into vision and real-time research. The Vision MCP allows your assistant to see by converting UI screenshots into code, performing OCR on technical documents, and interpreting complex architecture diagrams.

- **Server URL:** `https://www.zine.ai/mcp`
- **Auth Type:** OAuth 2.0 Authorization Code
- **More details:** [Zine developer information](https://www.zine.ai/#for-developers)
