## Article introduction

---

Federated through External Registry servers are developed by third parties and imported from an external registry. Cisco does not own these servers, and these servers are meant to be consumed by Webex AI clients. If you have any issues with the functionality of one of these servers, please reach out to the developer using the links below.

## Selected section

## ScrapeGraphAI

The ScrapeGraphAI MCP Server equips your AI assistant with advanced, LLM-driven web scraping capabilities, allowing you to transform webpages into clean Markdown, extract structured JSON, and perform multi-page crawling through simple chat commands.

- **Server URL:** `https://server.smithery.ai/@ScrapeGraphAI/scrapegraph-mcp/mcp`
- **Auth Type:** OAuth 2.0 Authorization Code
- **More details:** [ScrapeGraphAI MCP Server introduction](https://docs.scrapegraphai.com/services/mcp-server/introduction)
