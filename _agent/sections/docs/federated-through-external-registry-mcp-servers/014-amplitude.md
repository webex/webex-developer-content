## Article introduction

---

Federated through External Registry servers are developed by third parties and imported from an external registry. Cisco does not own these servers, and these servers are meant to be consumed by Webex AI clients. If you have any issues with the functionality of one of these servers, please reach out to the developer using the links below.

## Selected section

## Amplitude

The Amplitude MCP Server integrates digital analytics into your AI workflow, allowing product managers, analysts, and developers to query behavioral data, such as retention rates, conversion funnels, and A/B test results, using natural language.

- **Server URL:** `https://mcp.amplitude.com/mcp`
- **Auth Type:** OAuth 2.0 Authorization Code
- **More details:** [Amplitude MCP Server](https://amplitude.com/mcp-server?siteLocation=footer)
