## Event Handling

The embedded apps framework emits events in response to changes to the meeting, space, or application (Webex or Meeting Center client) in which an embedded app is running. You create event listeners to respond to these events, as needed. The following events are currently generated by the framework. The event object passed to your app's event listener contains details about the event.

See the Kitchen Sink embedded app on Github for examples of handling events.
