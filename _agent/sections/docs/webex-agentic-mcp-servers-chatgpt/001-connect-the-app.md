# ChatGPT

Connect ChatGPT to a Webex MCP server.

## Selected section

## Connect the App

1. Go to the sidebar in ChatGPT, or visit [chatgpt.com/apps](https://chatgpt.com/apps) to find apps.
2. If any Webex MCP server is enabled for you, it'll show up under the apps.
3. Select the Webex app and click **Connect**
4. Complete the OAuth flow to authorize the connection.
