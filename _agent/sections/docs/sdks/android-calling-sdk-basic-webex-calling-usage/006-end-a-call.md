## End a call

End a connected call using the `call.hangup()` method:

```kotlin
call?.hangup(CompletionHandler { result ->
        if (result.isSuccessful) {
            // Call has ended. Handle cleanup.
        } else {
            // Ending the call failed.
        }
    })
```
