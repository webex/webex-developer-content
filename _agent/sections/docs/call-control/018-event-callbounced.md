## Webhook Payload Schemas

This section provides detailed schema information for each telephony webhook resource.

### telephony_queue

Notification of call queue calls progression.

## Selected section

#### Event: callBounced

Notification when a call is bounced back to the queue after being offered to an agent.

##### Payload Fields

| **Field** | **Type** | **Description** |
|-----------|----------|-----------------|
| `queueEntry` | object | Queue entry information with `bounced` set to true (see <a href="https://developer.webex.com/docs/call-control#common-queue-entry-object">Common Queue Entry Object</a>). |
| `position` | integer | The new position of the call in the queue (if reordered). |
| `redirect` | object | Redirect details (see <a href="https://developer.webex.com/docs/call-control#redirect-information">Redirect Information</a>). |
