## Article introduction

[Webex App Hub](https://apphub.webex.com/) helps Webex customers discover apps that improve their workflows. List your app to showcase its benefits, explain its requirements, and give customers a clear way to get started.

## Find your development guide

Start with the customer outcome. These guides cover different app models and solution journeys; some products combine more than one app type.

| What you want to build | Start here |
| --- | --- |
| Call Webex APIs on behalf of a signed-in user. | [OAuth integrations](https://developer.webex.com/docs/integrations) and [Authentication](https://developer.webex.com/docs/authentication) |
| Run organization-level automation independently of an individual user's account. | [Service Apps](https://developer.webex.com/app-hub/docs/service-apps) |
| Provide virtual agents for Webex Contact Center customers. | [BYOVA provider guide](https://developer.webex.com/app-hub/docs/become-a-byova-provider) |
| Put your web application inside Webex meetings, spaces, or the sidebar. | [Embedded Apps developer guide](https://developer.webex.com/app-hub/docs/embedded-apps-guide) and [Meetings design guidelines](https://developer.webex.com/app-hub/docs/embedded-apps-design-guidelines-for-meetings) |
| Let users interact with your app through messages and spaces. | [Bots](https://developer.webex.com/app-hub/docs/bots) |
| Extend workspaces and Webex devices. | [Workspace Integrations](https://developer.webex.com/app-hub/docs/workspace-integrations) |

BYOVA uses a Service App as part of its provider onboarding workflow. Start with the BYOVA provider guide for that complete journey, then use the linked technical guides for implementation details.

For MCP servers and A2A agents, use [Choose Your App Hub App Type](https://developer.webex.com/app-hub/docs/choose-your-app-hub-app-type) to find the protocol-specific guides and check their availability and prerequisites before planning customer access.

Use the [Suite Sandbox](https://developer.webex.com/app-hub/docs/developer-sandbox-guide) for supported Webex Suite workflows or the [Contact Center Sandbox](https://developer.webex.com/app-hub/docs/sandbox_cc) for Contact Center testing. Check the selected sandbox's prerequisites and available features; a sandbox does not establish that every API or app type is available.
