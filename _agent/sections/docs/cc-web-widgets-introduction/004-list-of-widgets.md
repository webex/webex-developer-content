## Article introduction

Accelerate your integration with prebuilt Webex Contact Center (WxCC) UI components. The Contact Center Widgets package provides ready-to-use React components that let you add agent-facing capabilities like station login, agent state, task handling, and call controls with minimal code. Use the guides below to get started quickly.

## List of Widgets

The widgets package offers a set of ready-made components to enhance agent workflows:

- **StationLogin**: Render an agent station login & profile update experience.
- **UserState**: Display and manage agent states like available, idle, busy.
- **IncomingTask**: Present and respond to incoming tasks with accept or reject actions.
- **TaskList**: Display, toggle and manage multiple tasks in a list view.
- **CallControlCAD**: Provide active task capabilities such as hold/resume, recording, consult/transfer, end, and wrap-up.
- **OutdialCall**: Enable agents to make outbound calls directly from the contact center interface.
- **DigitalChannels**: Manage chat, email, and social media customer interactions in a single embeddable component.
- **AIAssistant**: Provide an AI Assistant panel with Real Time Assist suggestions for the active task.
