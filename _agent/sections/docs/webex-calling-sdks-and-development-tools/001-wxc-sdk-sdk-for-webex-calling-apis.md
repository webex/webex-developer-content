## wxc_sdk:  SDK for Webex Calling APIs

**wxc_sdk** is a simple SDK to work with Webex APIs, special focus on Webex Calling specific API endpoints.  This addresses API implementation requirement such as:

* JSON (de-)serialisation
* Authentication
* Retries
* Pagination
* Logging

[Get the wxc_sdk](<https://github.com/jeokrohn/wxc_sdk>)
