The Webex Meetings iOS Mobile SDK is a robust toolkit for incorporating Webex Meetings functionality into your mobile applications.

---



> **Info**
>
> Explore detailed documentation and code snippets for the iOS SDK on the [GitHub Wiki](https://github.com/webex/webex-ios-sdk/wiki).



The SDK allows developers to integrate audio, video, and screen sharing features into their iOS apps and supports participation in any type of Webex meeting. In addition, it offers a comprehensive set of methods for customizing the meeting experience.
