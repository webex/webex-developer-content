- Webex Contact Center Operation MCP Server is now publicly available.

- Webex Suite MCP server is now available in Codex.

- Webex Connect MCP server is now publicly available.
- The Webex Meetings and Cisco Workspaces MCP servers have been published on Gemini Enterprise. See [Webex Meetings MCP server on Gemini Enterprise](https://docs.cloud.google.com/gemini/enterprise/docs/connectors/webex-meetings) and [Cisco Workspaces MCP server on Gemini Enterprise](https://docs.cloud.google.com/gemini/enterprise/docs/connectors/cisco-workspaces).
- Webex Meetings and Webex Suite MCP servers are available on [Circuit](https://circuit.cisco.com/app/home) now.

- Webex Meetings and Cisco Workspaces MCP servers have been published on Quick.

- Vidcast MCP server is now publicly available.
