> Official Webex documentation: [View this page on Webex for Developers](https://developer.webex.com/blog/webex-for-developers-at-cisco-live-amsterdam)

At Cisco Live Amsterdam, Cisco DevNet and Webex for Developers have once again teamed up to showcase the Webex Developer Platform! Every day the DevNet Zone is open, attendees will be able to learn about how the Webex platform enables developers to power the hybrid experience.

### Webex DevNet Zone Takeover

On Thursday, February 9th, Webex will be taking over the DevNet Zone! There will be special Webex focused activities, drinks, and snacks, and even some giveaways throughout the day. Be sure to attend the capstone talk ([DEVNET-1605](https://www.ciscolive.com/emea/learn/sessions/session-catalog.html?search=DEVNET-1605#/))at 3:00 PM in the DevNet Theater to see how Webex enables developers to power the hybrid experience.

### Other DevNet Zone Activities

Come listen-in and learn at the speaker sessions, get your hands dirty building actual applications in the Webex workshops, and drop by the Webex booth to chat with Webex engineers, evangelists, and product managers.

#### Classroom Sessions

Here are all the Webex classroom sessions scheduled for Cisco Live Amsterdam:

- [DEVNET-1605: Powering Hybrid Experiences with Webex Platform](https://www.ciscolive.com/emea/learn/sessions/session-catalog.html?search=DEVNET-1605#/)
  - Presenters: Phil Bellanti &amp; Adam Weeks​
  - Session Date: Thurs, Feb 9th​
  - Session Time: 3:00 PM​
  - Technical Level: Introductory​
  - In the new hybrid world, organizations across industries are increasingly looking for ways to seamlessly collaborate while using different applications for their business needs The Webex platform is powering such experiences while enabling speed, agility, and resilience for these organizations.​

    In this Cisco Live session, we will explore some hero use cases, partner stories, and developer resources to help you build and shape these experiences. Join us and learn more about how different partners are enabling these possibilities using Webex platform.​

- [DEVNET-2369: Managing Your Calls with the Webex Call Controls API](https://www.ciscolive.com/emea/learn/sessions/session-catalog.html?search=DEVNET-2369#/)
  - Presenters: Phil Bellanti &amp; Joe Zanini​
  - Session Date: Mon, Feb 6th​
  - Session Time: 1:00 PM​
  - Technical Level: Intermediate
  - In this session, you will learn about how the Webex Call Controls API allows you to programmatically manage your calls. With Webex Integrations, you can build your own calling workflows. See first-hand how Webex development partners have utilized these APIs in their products to enhance functionality in the hybrid workplace.​

- [DEVNET-2675: Utilizing Webex Integrations for Authorization and Authentication​](https://www.ciscolive.com/emea/learn/sessions/session-catalog.html?search=DEVNET-2675#/)
  - Presenters: Phil Bellanti &amp; Joe Zanini​
  - Session Date: Tue, Feb 7th​
  - Session Time: 11:00 AM​
  - Technical Level: Intermediate
  - OAuth is a powerful way to allow users to grant permission over their accounts to third parties. Join the Webex Developer Evangelism team for a walk-through of how to create an OAuth flow so your Webex Integrations users can authorize your app to run on their accounts or simply authenticate with Login with Webex.​

- [BRKDEV-2260: Webex API "What's New" - The latest / greatest new features in Webex app development​](https://www.ciscolive.com/emea/learn/sessions/session-catalog.html?search=BRKDEV-2260#/)
  - Presenters: Dirk-Jan Uittenbogaard &amp; Phil Bellanti​
  - Session Date: Wed, Feb 8th​
  - Session Time: 1:30 PM​
  - Technical Level: Intermediate
  - Learn about the newest Webex API relases and other developer updates, and how they can be leveraged to power some exciting collaboration use cases.​

- [DEVNET-2100: Automating Migration to Webex Calling](https://www.ciscolive.com/emea/learn/sessions/session-catalog.html?search=DEVNET-2100#/)
  - Presenters: Shane Tuohy​
  - Session Date: Wed, Feb 8th​
  - Session Time: 10:00 AM​
  - Technical Level: Intermediate
  - Webex Calling has become radically more flexible and easier to migrate to with the addition of hundreds of NEW APIs and bulk provisioning capabilities. In this session you'll see a brief demo illustrating options available to export data from our legacy call control platform, Cisco Unified Communications Manager and drill down into the breath of new Webex Calling APIs and bulk provisioning tools with real-world examples. Attendees will also have an opportunity to ask the product owner of these new tools and APIs questions on what's available, limitations, as well as what is on the horizon.​
  
- [DEVNET-1850: Introducing Webex Connect and CPaaS APIs](https://www.ciscolive.com/emea/learn/sessions/session-catalog.html?search=DEVNET-1850#/)
  - Presenters: David Veevers​
  - Session Date: Wed, Feb 8th​
  - Session Time: 11:00 AM​
  - Technical Level: Introductory
  - Join us in this DevNet classroom session to explore the customer experience automation &amp; integration possibilities offered by the Webex Connect/CPaaS APIs &amp; SDKs. Webex Connect/CPaaS provide connectivity, integration &amp; tools enabling cloud CRM solutions to engage with customers via their preferred channels.​
