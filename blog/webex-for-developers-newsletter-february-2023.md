### 📞New: Detailed Call History API and Webex Calling Mobile SDK📞

While on the topic of Webex Calling APIs, there’s a great new endpoint for programmatically creating custom call reports - [Detailed Call History API](https://developer.webex.com/docs/api/v1/webex-calling-detailed-call-history). To get going quickly, check out this [new developer blog post](https://developer.webex.com/blog/webex-detailed-call-history-api)by Technical Solutions Architect, Justin Haefner, who shows us how to use the API to create reports with Python scripting.

Additionally, there’s a new Webex Calling Mobile SDK now in beta, for enabling users to make and receive calls in 3rd party mobile apps. To get more information about joining the beta, check out the [community announcement](https://community.cisco.com/t5/webex-for-developers/mobile-sdk-webex-calling-basic-features/td-p/4753424).

### ✨ New: Developer Guide for Creating Instant Meeting Links ✨

&#xa0;[Webex Instant Connect](https://instant.webex.com/) is a WebRTC based product that can be integrated in customer workflows to quickly create meeting links for hosts and guests via API. For example, Instant Connect enables healthcare staff and patients to meet in easy-to-use video telehealth consultations, scheduled directly from their Electronic Medical Record (EMR) portal​.

For a complete walkthrough of how the Instant Connect API works, what it does, and a step-by-step example using Postman, check out this [newly published developer guide](https://developer.webex.com/docs/instant-connect-meeting-links).

### 🪵 Webex API Changelog Highlights 🪵

&#xa0;The [Webex API Changelog](https://developer.webex.com/docs/api/changelog) has a lot of recent entries, so continue to keep a close on eye on it. Here are a few noteworthy ones from this month:

- **February 9, 2023 - New:** Added the attribute `panelist` to the `invitees` parameter in the [Create a Meeting API](https://developer.webex.com/docs/api/v1/meetings/create-a-meeting) for webinars only.
- **February 9, 2023 - New:** A new attribute, `expirationMinutes`, has been added to the [Join a Meeting API](https://developer.webex.com/docs/api/v1/meetings/join-a-meeting) to specify when the join meeting link expires.
- **February 17, 2023 - New:** As an admin user or a normal meeting host, you can now [list meeting attendee reports](https://developer.webex.com/docs/api/v1/meetings-summary-report/list-meeting-attendee-reports) for a site.
