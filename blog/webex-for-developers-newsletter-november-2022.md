### ✨ Browser SDK Update ✨

The [Browser (JavaScript) SDK](https://developer.webex.com/docs/sdks/browser) received a nice update to add Background Noise Reduction (BNR) in Webex audio. This new Browser SDK feature combines advanced deep learning, speech science, and audio processing technologies to distinguish between background noise and speaker voices in any language.

Check out this [great blog](https://developer.webex.com/blog/background-noise-reduction-added-to-webex-browser-sdk) from Webex Software Engineer, Kesava Krishnan Madavan, to learn all about this new feature.

### 🪵 Webex API Changelog Highlights 🪵

The [Webex API Changelog](https://developer.webex.com/docs/api/changelog) is rolling on, so be sure to check on that page frequently. Here are some noteworthy recent entries:

- [List Transcripts API](https://developer.webex.com/docs/api/v1/meeting-transcripts/list-meeting-transcripts) update 10/18:&#xa0; All transcripts for the current user at a given site can now be listed and two new response parameters are included: `meetingTopic` and `status`.
- New 10/27 - [Create](https://developer.webex.com/docs/api/v1/meetings/create-invitation-sources) &amp; [List](https://developer.webex.com/docs/api/v1/meetings/list-invitation-sources) Invitation Sources API: *Invitation Sources* allows the host or an administrator to list or assign a custom `sourceID` to a meeting or webinar invitation, to track where it originated from.
- [Create a Meeting API](https://developer.webex.com/docs/api/v1/meetings/create-a-meeting) update 10/27: Now supports the creation of ad-hoc meetings (previously for scheduled meetings only).
