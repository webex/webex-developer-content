### ✨ New Meetings API Updates ✨

Developers can now get more control over how recordings and webinar resources are managed with some powerful new Webex Meetings APIs. In a [new blog](https://developer.webex.com/blog/webex-meetings-api-updates), Senior Developer Evangelist David Liedle walks us through the new capabilities.

If you missed the webinar, you can [watch the recording now](https://developer.webex.com/webinars).

### 🪵 Webex API Changelog Highlights 🪵

The [Webex API Changelog](https://developer.webex.com/docs/api/changelog) keeps rolling into the end of the year, so be sure to frequently keep tabs on that page. Here are some noteworthy recent entries:

* **Breaking change - ***11/10/22***:** The [Download Transcript API](https://developer.webex.com/docs/api/v1/meeting-transcripts/download-a-meeting-transcript) no longer requires `meetingId` as a parameter.
* **New** - *11/10/22*: We now provide the ability to create public spaces in the [/rooms API](https://developer.webex.com/docs/api/v1/rooms).
* **Major change**- *11/16/22*: Roles have been renamed in the [/roles API](https://developer.webex.com/docs/api/v1/roles). The current `Sales Administrator` role will be renamed to `Partner Administrator`.
