### ☝️Webex Meetings REST API Updates ☝️

As part of on-going efforts to add features to the Webex Meetings REST APIs:

- A meeting user can now [create a meeting](https://developer.webex.com/docs/api/v1/meetings/create-a-meeting), [list meetings](https://developer.webex.com/docs/api/v1/meetings/list-meetings) and [update a meeting](https://developer.webex.com/docs/api/v1/meetings/update-a-meeting) with meeting options.
- A meeting user can now [list meetings](https://developer.webex.com/docs/api/v1/meetings/list-meetings) by different values of`scheduledType`such as`meeting`,`webinar`and`personalRoomMeeting`.

### ⚠️ Reminder: Webex XML API Deprecation ⚠️

Another reminder that the Meetings related XML APIs will be [deprecated](https://developer.webex.com/docs/webex-xml-api-deprecation-announcement), and the End-of-Support (EoS) date is April 30, 2023. Up to this date, Cisco will continue to resolve bugs, however, new features will only be rolled out on the REST APIs suite. End-of-life (EoL) date is October 31, 2023, when the XML APIs will be retired. For more information on how to migrate from XML to REST APIs, see the [Webex Meetings XML to REST Migration Guide](https://developer.cisco.com/docs/webex-meetings/#xml-to-rest-migration-guide).
