### ☎️Get Started with the Webex Call Control APIs

The Call Control APIs for Webex Calling can perform user calling actions and provide information about the user’s calls, to power a variety of use cases for custom calling clients, dynamic call routing, and populating agent dashboards &amp; widgets. [Check out this new blog](https://developer.webex.com/blog/webex-calling-getting-started-with-call-control-apis) from Webex Developer Evangelist, Phil Bellanti, for a comprehensive overview of the Call Control API endpoints, webhooks that are available, and resources to get started quickly.

### 📲Android SDK: Utilizing Dynamic Feature Modules

Android mobile developers are creating more complex apps than ever before and are continually looking for new ways to increase efficiency. Following Android’s recommendation to use dynamic modules for larger applications, you can now seamlessly integrate the Webex Android SDK into dynamic modules. This breakthrough not only reduces app (.apk) size but also empowers you to leverage the tight compatibility of the Webex SDK. Software Engineer, Rankush Kumar, explains we've “cracked the code” on dynamic feature modules in an [informative new blog post](https://developer.webex.com/blog/unleashing-the-power-of-the-android-sdk-with-dynamic-feature-modules).

### 📝Webex API Changelog Highlights

The [Webex API Changelog](https://developer.webex.com/docs/api/changelog) had several new entries over the last month and we continue to recommend checking it frequently. Here are a few important ones to note:

- **Aug. 30<sup>th</sup>, 2023 - NEW**: The Webex Calling [Devices](https://developer.webex.com/docs/api/v1/devices)and [Workspaces](https://developer.webex.com/docs/api/v1/workspaces) APIs now have the ability to list and add Webex Calling Workspaces and Devices, to onboard Webex Calling devices by MAC address, to manage Device Call Settings with Third-party device activation, and to manage Device Line Key templates.
- **Sep. 7<sup>th</sup>, 2023 - NEW**: Two new attributes, `hostEmail` &amp; `hostDisplayName`, are returned in the response of the [List Recordings for an Admin or Compliance Officer API](https://developer.webex.com/docs/api/v1/recordings/list-recordings-for-an-admin-or-compliance-officer).
- **Sep. 13****<sup>th</sup>, 2023 - NEW**: The `autoAcceptRequest` parameter has been added to the request of the [Update Meeting Registration Form API,](https://developer.webex.com/docs/api/v1/meetings/update-meeting-registration-form) and has also been added to the response of the [Update Meeting Registration Form](https://developer.webex.com/docs/api/v1/meetings/update-meeting-registration-form) and [Get Registration Form for a Meeting API](https://developer.webex.com/docs/api/v1/meetings/get-registration-form-for-a-meeting).
