Hello, Webex developers! As usual, there are a lot of new things to share about the Webex for Developers platform. Here are some noteworthy ones that you’ll want to check out.

### 🎉 Webex Developer Portal and API Updates 

We've got the following updates on the Webex Developer Portal and APIs:

- The [Webex Developer Portal home page](https://developer.webex.com/)  has been redesigned based on the community’s feedback! Additionally, developers can now obtain their very own [Webex sandbox](https://developer.webex.com/docs/developer-sandbox-guide) for testing their apps. Come and see how building with Webex is now better than ever!
- The Webex Meetings APIs also received an update recently. Now a meeting user can now [create a meeting](https://developer.webex.com/docs/api/v1/meetings/create-a-meeting) and [list meetings](https://developer.webex.com/docs/api/v1/meetings/list-meetings) in a [personal room](https://help.webex.com/en-us/article/nul0wut/Webex-Personal-Rooms-in-Webex-Meetings) by specifying the `scheduledType` value as `personalRoomMeeting.`

### ⚠️Important Notice: Webex Meetings XML APIs ⚠️

The [Meetings related XML APIs](https://developer.webex.com/docs/webex-xml-api-deprecation-announcement) will be deprecated, and the End-of-Support (EoS) date is April 30, 2023. Up to this date, Cisco will continue to resolve bugs, however, new features will only be rolled out on the [REST APIs suite](https://developer.webex.com/docs/meetings). End-of-life (EoL) date is October 31, 2023, when the XML APIs will be retired. 

Existing customers are encouraged to start migrating to REST APIs before the EoL date. Please see the [XML to REST Migration Guide](https://developer.cisco.com/docs/webex-meetings/#!xml-to-rest-migration-guide) for more information about how to get started. If you have any questions, reach out to the great [Webex Dev Support](https://developer.webex.com/support) team for assistance.
