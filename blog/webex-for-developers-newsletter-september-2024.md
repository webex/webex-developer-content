Hello to our Webex Developers! We have a lot of new and updated content to share with you in this month’s newsletter, including our SDKs, APIs, and more. Keep reading to get all the exciting details!

### 👨🏻‍🔧 New! Service App Guest-to-Guest Meetings Guide

In [newly published developer guide](https://developer.webex.com/docs/service-apps-as-g2g-meeting-facilitator-guide), we explain how Webex Service Apps, in combination with a new subscription, can be used to automatically schedule meetings that do not include registered Webex users and are *only* between guests. This opens up a lot of flexible use cases for developers. Learn how it all comes together in the guide and start building today.

### 📲 Webex Mobile SDK: Seamless Meeting Movement and External Camera Support

Our Mobile SDK engineers also made some great files available for capturing an audio dump in iOS and Android. These files provide developers with valuable information about the audio streams during calls or meetings, that can be analyzed to identify and resolve audio-related issues. Check out the guides on GitHub ([(iOS](https://github.com/webex/webex-ios-sdk/wiki/Troubleshooting-Audio-on-Mobile-SDKs)/[Android](https://github.com/webex/webex-android-sdk/wiki/Troubleshooting-Audio-on-Mobile-SDK)) and watch the helpful *Vidcasts* ([iOS](https://app.vidcast.io/share/933b9ee1-47ec-4fa7-bd1a-54d4ee885233)/[Android](https://app.vidcast.io/share/9cbcf215-f18f-4a25-8603-72478eb9e973)) to get started fast.

### 📣 New! Webex Web SDK Dedicated Changelog Site

The Webex Web (JS) SDK now has a [dedicated changelog site on GitHub](https://webex.github.io/webex-js-sdk/changelog/), which gives developers a dynamic view of updates across each different version. Instead of hunting for specific releases and scrolling through every change made, developers can now select the Web SDK version number and package name, for quick access to the info they need. Head over to the new site and try it out.

We also have a helpful [usage guide to watch on Vidcast](https://app.vidcast.io/share/072f82d1-3735-4a13-8c74-1ece59723ff3) that will show you how to best utilize the new changelog site.

### 🗓️ Webex Contact Center APIs - New Versions

As noted in the [Webex Contact Center API changelog](https://developer.webex.com/webex-contact-center/docs/api/changelog/webex-contact-center) on **September 8, 2024**, the following APIs have a new version added: [List Skill API](https://developer.webex.com/webex-contact-center/docs/api/v1/skill/list-skills), [List Team API](https://developer.webex.com/webex-contact-center/docs/api/v1/team/list-teams), [Create a Team API](https://developer.webex.com/webex-contact-center/docs/api/v1/team/create-a-new-team), [List Entry Points API](https://developer.webex.com/webex-contact-center/docs/api/v1/entry-point/list-entry-points), and [List Contact Service Queue](https://developer.webex.com/webex-contact-center/docs/api/v1/contact-service-queues/list-contact-service-queues).

### 📒 Webex API Changelog: Major Announcement

September has several entries in the [Webex API Changelog](https://developer.webex.com/docs/api/changelog) and we always recommend checking this page frequently to stay up to date. There is one very important announcement that we want to call out again here:

- **August 23, 2024 - MAJOR:** We are formally announcing that the Web Meetings SDK version v2 will reach its end-of-life (EOL) on September 30, 2025. The v1 SDKs are already EOL. As indicated on this change log in March and May we strongly encourage all users to migrate to SDK v3 (latest version: `webex@3.4.0)` at your earliest convenience to continue getting SDK support and feature upgrades while avoiding service disruptions on the Webex Suite Meetings Platform. Please refer to our [Migration Guide](https://developer.webex.com/docs/sdks/webex-meetings-sdk-migrating-2-to-3) for detailed instructions on making the transition.
