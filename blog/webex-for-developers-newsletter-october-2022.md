### 🆕 Developer Platform Updates🆕

There are more new updates to learn about this month:

- Webex Developer Evangelist, Aaron Burns, highlights some important new changes in the [Webex People API Update](https://developer.webex.com/blog/webex-people-api-updates) for interacting with Webex user data.
- The Webex Mobile SDKs ([iOS](https://github.com/webex/webex-ios-sdk/blob/master/CHANGELOG.md#370) and [Android](https://github.com/webex/webex-android-sdk/blob/master/CHANGELOG.md#370)) were updated to v3.7, adding new methods for breakout session support, managing captcha codes, and monitoring network status changes.

### 🪵 Webex API Changelog Rollcall 🪵

The [Webex API Changelog](https://developer.webex.com/docs/api/changelog) keeps on rolling along, so be sure to keep tabs on that page. Here are some recent items that deserve special attention:

- *New Administrator API*: [Session Types](https://developer.webex.com/docs/api/v1/session-types) define the features and options that are available to users for scheduled meetings.
- New Site-Level API: &#xa0;[Site](https://developer.webex.com/docs/api/v1/site/) lets you update features, options and privileges that are configured for your Webex service sites.
- There’s a breaking change in the [meetingParticipants REST resource](https://developer.webex.com/docs/api/v1/meeting-participants/list-meeting-participants) to avoid race conditions.
