### ☝️ API Updates and Changes ☝️

The Webex APIs continue to be improved with recent updates, fixes, and features. Here are some of the latest noteworthy changes:

- 🚨 NEW: Developers can now leverage the [Create a Meeting API](https://developer.webex.com/docs/api/v1/meetings/create-a-meeting) to schedule and configure webinars on the new [Webex Webinars Platform](https://www.webex.com/webinar.html) . This API also allows management of webinar registrations and panelists to build a complete, automated solution. Developers with an existing [Webex Events (classic)](https://help.webex.com/en-us/article/t66fpw/Webex-Events-(classic)) integration particularly must try this out.
- ⚠️ IMPORTANT CHANGE: Due to increased privacy requirements we are going to disallow [lookup of users by email](https://developer.webex.com/docs/api/v1/people/list-people) (example `GET /people?email=abc@domain.com`) after April 30, 2022.
- ⚠️ IMPORTANT CHANGE: Starting April 27, 2022, API endpoints will no longer accept UUID formatted IDs. The Webex API uses IDs encoded as `Y2lZZZZZZZZZZZZZZZZZZ` (for example, the [room id as shown under 'Response Properties'](https://developer.webex.com/docs/api/v1/rooms/list-rooms))
- Reminder: Keep up to date with the [Webex for Developers changelog](https://developer.webex.com/docs/api/changelog), which lists all the latest changes to the platform.
