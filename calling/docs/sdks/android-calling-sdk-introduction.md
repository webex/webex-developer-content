The Webex Android Mobile Calling SDK integrates calling functionality into mobile apps, supporting both Unified Communication Manager (UCM) and Webex Calling.

---



> **Info**
>
> Explore detailed documentation and code snippets for the Android SDK on the [GitHub Wiki](https://github.com/webex/webex-android-sdk/wiki).



The SDK enables dialing and receiving calls, and includes additional features such as call holding, transferring, and merging.



> **Info**
>
> There are multiple versions of the Mobile Android SDK. Use the full SDK for UCM calling integration. For more information, see: [Integrating the Android SDK](https://developer.webex.com/docs/sdks/android-calling-sdk-integrate-the-sdk).
